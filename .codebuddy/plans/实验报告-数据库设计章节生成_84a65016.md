## 产品概述

为"软件综合实践报告"生成完整的"数据库设计"章节内容。该项目为 Python 职位分析系统，使用 SQLite 作为数据库（单表 data），需按实验报告模板要求完成4个子章节的撰写。

## 核心功能

- 需求分析：描述系统数据需求、绘制数据流图（文字描述+图示说明）、编写数据词典
- 概念结构设计：使用 E-R 图描述实体及关系，提供 PowerDesigner CDM 模型说明
- 逻辑结构设计：将概念模型转换为关系模式，提供 PowerDesigner PDM 模型说明
- 物理设计：使用 SQL 语言实现数据库结构定义，包括创建表语句、索引、视图、主要查询语句

## 技术栈

- 文档生成：docx skill（生成格式规范的 Word 文档）
- 数据库：SQLite 3.x

## 实现方案

### 策略

基于项目实际使用的 SQLite 数据库（单表 `data`），生成可直接复制到实验报告中的完整"数据库设计"章节内容，并输出为 .docx 格式文档。

### 关键决策

1. **数据库选型说明**：在报告中说明选用 SQLite 的原因（轻量级、嵌入式、无需独立服务器进程、适合演示场景），并对比 MySQL 说明差异。
2. **数据流图**：采用文字描述 + 结构化文本方式呈现（因无法在 docx 中直接画图，提供描述让用户可自行用 Visio/ProcessOn 绘制）。
3. **E-R 图**：采用文字描述实体、属性、关系的方式呈现（提供 Mermaid 代码，用户可转换为图片插入报告）。
4. **PowerDesigner 模型**：提供详细的模型建立步骤说明，以及在 PowerDesigner 中对应的操作描述（因无法生成 .pdm 文件）。
5. **SQL 语句**：提供完整的 SQLite DDL 语句（建表、索引、视图）及主要查询语句。

### 数据流图描述（文字版）

```
外部实体：用户
    ↓（输入查询条件）
处理过程：Web前端（Flask）
    ↓（HTTP请求）
处理过程：后端API（app.py）
    ↓（SQL查询）
数据存储：SQLite数据库（data.db）
    ↓（查询结果）
处理过程：数据分析模块（analysis/）
    ↓（统计结果）
处理过程：Web前端展示
    ↓（可视化结果）
外部实体：用户
```

### E-R 图描述

- 实体：职位信息（Job）
- 属性：职位ID、职位名称、公司名称、工作地点、最低薪资、最高薪资、发布日期、学历要求、工作经验、职位描述
- 主键：职位ID（id）
- 关系：本系统为单实体模型，无实体间关联关系
